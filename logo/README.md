# App and brand icons

[Apps.json](../Apps.json) contains one selected image per recognizable app, brand or product. Prefer a clear native mark or app tile over alternative skins, character artwork, decorative recolorings and redundant light/dark versions. Keep each identity's own colors.

Separate products remain separate, such as Apple, App Store, Apple Intelligence and Apple TV. Clearly named games also retain one app icon each. Anonymous illustrations and decorative pictures are excluded.

The standalone `Apps144px.json` index has been removed. The two 144 px originals for Arc and Clash are retained because the larger candidates were decorative variants; they are indexed directly by `Apps.json`. Other size-specific duplicate copies have been removed.

Paths for selected assets are retained. Removed variants can be recovered from Git history. App/brand artwork remains subject to the original creators' rights and attribution.
