# UI symbols

[UI.json](../UI.json) contains 20 distinct utility symbols. Each PNG is redrawn from the editable SVG with the same basename in [source/](source/).

All symbols share a 1024 × 1024 RGBA canvas, a 928 × 928 light tile at (48, 48), 128 px corner radius, transparent outer padding, rounded strokes and the USA-1 inspired coral/indigo gradients. Most strokes are 36 px; smaller internal details use 22–32 px and emphasis uses 42–52 px. The tile shades from white to `#DEDEDE`.

The retained themes cover clicking, approval, age restriction, signal strength, refresh, applications, routing, highlight, data transfer, equalizer, video, lightning, globe, internet, radar, rocket, satellite, cutting, broadcast and toggles. The globe-on-stand and internet grid have distinct silhouettes. Index names describe the functions; legacy PNG paths are retained where selected.

Alternative variants, ornamental magic/astrology illustrations and ambiguous novelty images have been removed. Original drawings remain recoverable from Git history. These SVG drawings were created for this repository.
